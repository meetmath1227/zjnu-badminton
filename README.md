# 浙师大羽毛球场地查询

一个无需安装、无需后台服务的网页，支持 **综合馆羽毛球馆** 和 **北田羽毛球馆（室内）**。

## 使用

1. 打开网页，选择综合馆或北田馆。
2. 粘贴从学校预约网站取得的完整登录链接。
3. 网页自动查询当前开放日期的余量，按日期、时段列出场地号。
4. 点击场地号选择一片场地、一个时段。切换场馆时会清除之前的选择。
5. 点击“下一步”，核对场馆、日期、时间和费用，阅读须知并勾选，再点击“确认预约”。

当前仅接入网站提供的免费预约方式；收费或其他支付方式请到官网完成。

## 网络和登录信息

- 网页可由 GitHub Pages 提供公网访问；实时查询仍需要使用者当前网络能访问 `https://tycg.zjnu.edu.cn`，托管网页不会改变学校系统本身的网络访问范围。
- 登录链接仅保留在当前页面内存，不写入浏览器持久存储，也不发送给 GitHub 或其他中转服务；页面直接向学校网站查询和提交。
- 仓库不包含任何人的登录链接、个人资料、实际预约记录或 GitHub 授权信息。
- 场地余量随时可能变化，提交前会重新核对。网络中断导致提交结果不明时，网页不会自动重试，请先在官方“我的场地”核实。

## 场馆须知

学校预约系统的须知明确禁止外挂、脚本、连点器、自动化框架及第三方抢票程序，并提示可能封号。网页会在确认前展示学校返回的原文和官方入口，请阅读并自行决定使用官方流程。本项目不是学校官方产品，不提供自动抢场、定时抢场或循环提交。

## GitHub Pages

在仓库的 **Settings → Pages** 中设置 **Deploy from a branch → main → / (root)**。保存并等待发布完成后，使用 GitHub 显示的站点地址。

本项目为单文件静态网页：`index.html`。可以直接下载后双击打开，也可以用任意静态网站服务托管。没有构建或安装依赖步骤。

## 验证范围

综合馆和北田馆的场地列表、开放日期、余量接口已读取验证。选择、确认、防止重复提交、场馆切换和异常结果处理使用模拟响应验证；开发过程中没有提交真实预约。实际预约结果应以学校网站为准。
